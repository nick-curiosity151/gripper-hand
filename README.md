# 見て、触って、つかみ方を変えるグリッパー

**― 柔らかさを指で知るPhysical AIハンドへ**

見た目は同じでも、柔らかさは触らないと分からない。カメラで大きさを見て素早く寄せ、指先の力センサー（FSR）とサーボの位置フィードバックで力を加減して止まる、潰さずつかむグリッパーです。

「Arduino Physical AI チャレンジ 2026」応募作品です。

- ProtoPedia：https://protopedia.net/prototype/10704
- デモ動画：https://www.youtube.com/watch?v=b_JT2KVtTXk

## 仕組み（見る → 触って判断する → 動く）

1. **見る**：USBカメラで物体を真上から見て、幅を推定する（PC、OpenCV）
2. **動く**：幅＋3mmまで素早く寄せる
3. **触って判断する**：少しずつ閉じながら、Arduinoが50Hzで判定する
   - **HOLDING**：左右のFSRがしきい値を超えた → つかめた
   - **STALL**：指令した位置と、位置フィードバックから求めた実際の指の位置がずれた → 当たって止まった。少し戻して保持
   - **LIMIT**：全閉まで何にも触れなかった → 開いて、少し広めの位置からやり直す

比較のため、「固定制御」「視覚のみ」「視覚＋触覚」の3条件を切り替えて実験できます。

## ハードウェア

| 部品 | 接続 |
| --- | --- |
| Arduino UNO R4 WiFi | PCとUSB |
| 小型グリッパーキット（フィードバックサーボ付き、Pololu #3551） | 信号 D9、位置フィードバック A2、電源は単三充電池×4 |
| FSR402の感圧部 ×2（左右の指先） | A0 / A1。それぞれ10kΩ抵抗で分圧 |
| USBカメラ Logicool C270n | PCのUSB。三脚で真上から撮影 |

サーボの電源のGNDは、ArduinoのGNDとつないでください。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `gripper_test/gripper_test.ino` | Arduinoのスケッチ。サーボ制御、FSRと位置フィードバックの読み取り、状態判定（50Hz）、自動校正 |
| `grasp_runner.py` | 実験用のメインプログラム。カメラで幅を測り、3条件でつかみ、結果をCSVに記録 |
| `vision_measure.py` | 背景差分で物体の幅を測る。ROIとスケール（px/mm）の設定もここで行う |
| `cam_test.py` | カメラの映りを確認する |
| `logger.py` | Arduinoのシリアル出力をCSVに保存する |
| `softness_ai.py` | 記録した触覚データから、AI（ロジスティック回帰）が柔らかさを見分けられるかを一個抜き交差検証で確かめる（numpyのみ） |

## 使い方（Windows）

### 準備

```powershell
pip install -r requirements.txt
```

Arduino IDE 2 で `gripper_test/gripper_test.ino` を書き込みます。シリアルモニタは閉じておいてください（PythonとCOMポートを取り合うため）。

### 1. カメラの設定（初回、カメラを動かしたとき）

```powershell
python vision_measure.py
```

- `a`：測る範囲（ROI）をドラッグで指定
- `k`：既知の長さの2点をクリックし、長さ（mm）を入力してスケールを決める。物体の上面の高さで校正すると誤差が小さくなる
- `b`：背景を記録、`m`：幅を測る、`q`：終了

設定は `vision_config.json` に保存されます。

### 2. 実験

```powershell
python grasp_runner.py --obj sponge --tag v3
```

- `c`：グリッパーの自動校正（位置フィードバックの対応表を作る）
- `b`：背景を記録（指を動かして、指の縁を無視するマスクも作る）
- `1` / `2` / `3`：条件の切り替え（固定制御 / 視覚のみ / 視覚＋触覚）
- `Space`：1回つかむ
- `y` / `n`：成功 / 失敗として記録、`x`：記録しない
- `o`：開く、`q`：終了

結果は `logs/trials.csv`（1回ごとのまとめ）と `logs/raw_*.csv`（50Hzの生データ）に保存されます。

### Arduinoのシリアルコマンド（115200bps）

| コマンド | 動作 |
| --- | --- |
| `o` / `g` | 開く / 少しずつ閉じながら判定する把持を開始 |
| `u<µs>` / `a<deg>` | 指定したパルス幅 / 角度へ動かす |
| `s` | 停止 |
| `c` | 自動校正 |
| `p` / `r` | ストリーミングを止める / 再開する |

出力（50Hz、CSV）：`ms,us,fsrL,fsrR,fb,diff,wmm,state`

## 実験結果

| 物体 | 条件 | 保持 | 押しつぶし率 | つかむ力（FSR） | 時間 |
| --- | --- | --- | --- | --- | --- |
| スポンジ（幅13.4mm） | 固定制御 | 5/5 | 72% | 833 | 1.0秒 |
| スポンジ | 視覚のみ | 4/5 | 0% | 15 | 1.0秒 |
| スポンジ | 視覚＋触覚 | 5/5 | 41% | 680 | 2.9秒 |
| はやぶさ2模型（幅16.0mm） | 固定制御 | 4/4 | 27% | 502 | 1.0秒 |
| はやぶさ2模型 | 視覚のみ | 5/5 | 20% | 528 | 1.0秒 |
| はやぶさ2模型 | 視覚＋触覚 | 6/6 | 15% | 480 | 1.6秒 |

### 追加実験：AIで柔らかさを見分ける

FSRが反応してから「指が進んだ距離」と「指先の最大の力」だけを使い、ロジスティック回帰で柔らかい物（スポンジ）と硬い物（はやぶさ2模型）を判定しました。物の大きさは使っていません。一個抜き交差検証で、一定の力で押し込んだときは19回中19回、触れてすぐ止めたときは21回中15回正解でした。

```powershell
python softness_ai.py logs
```
詳しい説明はProtoPediaのページを見てください。
